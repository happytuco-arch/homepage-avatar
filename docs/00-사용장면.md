# 00 · 사용 장면과 조건

## 한 줄 장면

방문자(교수님·동료)가 앱을 실행하면, 내 아바타가 내 홈페이지를 직접 넘기며
목소리로 소개하고, 인터뷰어가 던지는 질문에 스스로 답한 뒤 90도로 인사하고 끝나는 프로그램.

## 장면 순서

1. 앱 창에 실제 사이트(https://my-homepage-jh-f22e.vercel.app)가 열린다.
2. 정장 차림의 아바타가 화면 오른쪽 밖에서 걸어 들어와 인사한다.
3. 아바타가 메뉴를 직접 눌러 Works → Papers → Assignments 순으로 이동하고,
   설명하는 부분을 테두리로 짚으며 스크롤한다.
4. 각 페이지 사이에 인터뷰어 목소리가 질문하고("이 게임은 왜 만들었어요?"),
   아바타가 실제 사이트 내용을 근거로 답한다.
5. 말하는 동안 자막이 글자 단위로 따라가고, 아바타 입이 소리에 맞춰 움직인다.
6. 마지막에 아바타가 90도로 인사하고, "다시 보기" 버튼이 나타난다.
7. 보는 사람은 언제든 일시정지 · 건너뛰기 · 직접 질문(텍스트)을 할 수 있다.

## 꼭 지킬 조건

- Windows와 Mac 모두에서 동작한다 (Electron 데스크톱 앱).
- ElevenLabs 키는 앱 메인 프로세스의 `.env`에만 둔다. 화면(렌더러)·사이트·깃에 노출 금지.
- TTS는 ElevenLabs, 목소리는 기본 목소리 두 개(아바타 · 인터뷰어).
- 생성한 음성은 파일로 캐시해 같은 대사는 다시 생성하지 않는다(크레딧 절약).
- 키가 없거나 인터넷이 끊기면 컴퓨터 내장 음성으로 자동 전환해 끝까지 재생한다.
- 대본의 사실(작품·논문·과제 내용)은 실제 사이트 데이터에서만 가져온다. 지어내지 않는다.
- my-homepage 코드는 수정하지 않는다. 앱은 사이트를 바깥에서 조작만 한다.
