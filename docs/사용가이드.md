# Homepage Avatar 사용 가이드

앱을 켜면 정장 차림의 아바타가 걸어 들어와 인사합니다. 그다음 제 홈페이지를 직접 넘기면서
작품(Works), 논문(Papers), 수업 과제(Assignments)를 차례로 소개하고, 마지막에 90도로 인사합니다.
보는 사람은 언제든 멈추거나 건너뛸 수 있고, 아바타에게 직접 질문할 수도 있습니다.

## 1. 설치하고 실행하기

### Windows
1. `HomepageAvatar-1.0.0-win.zip`의 압축을 풉니다.
2. 폴더 안의 `HomepageAvatar.exe`를 더블클릭합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 서명하지 않은 앱이라 뜨는 경고입니다.

### Mac
1. `HomepageAvatar-…-mac.zip`의 압축을 풀고 `HomepageAvatar.app`을 응용 프로그램 폴더로 옮깁니다.
2. "손상되었기 때문에 열 수 없습니다"라는 창이 뜨면 터미널에서 아래 한 줄을 실행한 뒤 다시 엽니다.
   ```
   xattr -cr /Applications/HomepageAvatar.app
   ```
3. 마이크 권한을 물으면 **허용**을 누릅니다. 말로 질문할 때만 씁니다.

### (선택) 실제 목소리와 AI 답변 켜기
키가 없어도 앱은 처음부터 끝까지 동작합니다. 이때는 컴퓨터 내장 음성과 미리 만든 답을 씁니다.
더 자연스럽게 하려면 `.env` 파일을 실행 파일과 같은 폴더에 두세요(형식은 `.env.example` 참고).
- `ANTHROPIC_API_KEY`: 사이트 내용을 대화체로 각색해 소개하고, 자유로운 질문에도 답합니다.
- `ELEVENLABS_API_KEY`: 아바타와 인터뷰어가 서로 다른 실제 목소리로 말하고, 입 모양이 글자에 맞춰 움직입니다. 마이크 질문도 켜집니다.

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 화면 전체 | 실제 홈페이지. 아바타가 메뉴를 누르고 스크롤합니다 |
| 오른쪽 아래 | 3D 아바타 |
| 아래 가운데 | 자막. 말하는 글자를 따라 진하게 바뀝니다. 파란 이름은 인터뷰어, 주황 이름은 아바타입니다 |
| 왼쪽 아래 | 일시정지 · 건너뛰기 · 질문 입력 · 🎤(말로 질문하기) · 현재 모드 표시 |

## 3. 사용 순서

1. **앱을 켜면 자동으로 시작합니다.** 아바타가 걸어 들어와 손을 흔들며 인사합니다.
2. 아바타가 위쪽 메뉴를 가리키면 **손 모양 커서**가 날아가 메뉴를 누르고, 소개하는 카드에 **주황 테두리**를 칩니다.
3. 중간중간 **인터뷰어**가 질문하고 아바타가 답합니다.
4. 마지막에 아바타가 **90도로 인사**하고, 자막 오른쪽에 **↻ 다시 보기** 버튼이 나타납니다.

## 4. 주요 기능

- **일시정지 / 이어 보기:** 버튼이나 스페이스 바를 누릅니다.
- **건너뛰기:** 지금 장면을 끝내고 다음 페이지로 넘어갑니다.
- **직접 질문(글자):** 입력란에 질문을 쓰고 **묻기**를 누릅니다. 아바타는 지금 하던 문장까지만 말한 뒤 답하고, 답이 끝나면 하던 소개를 이어 갑니다.
- **직접 질문(말):** 🎤를 누르고 말한 다음 🎤를 한 번 더 누릅니다. ElevenLabs 키가 있을 때만 보입니다.
- **사이트에 없는 질문:** 아바타는 지어내지 않고 "제 홈페이지에는 그 내용이 없어요"라고 답합니다.
- **모드 표시:** 왼쪽 아래 작은 글씨로 지금 쓰는 대본·목소리·자료의 종류를 보여 줍니다.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 소리가 안 남 | 컴퓨터 음량과 출력 장치를 확인합니다. 키가 없으면 내장 음성으로 말합니다 |
| 목소리가 하나로만 들림 | 키가 없을 때 Windows는 한국어 내장 음성이 하나뿐이라 높낮이로만 구분합니다 |
| 아바타가 메뉴를 못 누름 | 인터넷 연결을 확인합니다. 홈페이지가 열려 있어야 합니다 |
| 첫 실행이 느림 | 키가 있을 때 처음 한 번 대본과 음성을 만듭니다. 두 번째부터는 저장된 것을 씁니다 |
