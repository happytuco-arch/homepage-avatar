# Homepage Avatar 사용 가이드

앱을 켜면 정장 차림의 3D 아바타 "JH 아바타"가 걸어 들어와 인사합니다.
그다음 실제 홈페이지(https://my-homepage-jh-f22e.vercel.app) 위를 직접 걸어 다니며
작품(Works) → 논문(Papers) → 과제(Assignments) → 소개(About) 순서로 발표하고,
마지막에 90도로 인사합니다. 인터뷰어가 중간중간 질문하고, 보는 사람도 언제든 직접 질문할 수 있습니다.
발표는 처음부터 끝까지 약 8분입니다(질의응답 제외).

## 1. 설치하고 실행하기

실행 파일은 https://github.com/happytuco-arch/homepage-avatar/releases 에서 받습니다.

### Windows
1. `HomepageAvatar-1.0.0-win.zip`의 압축을 풉니다.
2. 폴더 안의 `HomepageAvatar.exe`를 더블클릭합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(서명하지 않은 앱이라 뜨는 경고입니다).

### Mac (Apple Silicon · M1 이후)
1. `HomepageAvatar-1.0.0-arm64-mac.zip`의 압축을 풀고 `HomepageAvatar.app`을 응용 프로그램 폴더로 옮깁니다.
2. "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 아래 한 줄을 실행한 뒤 다시 엽니다.
   ```
   xattr -cr /Applications/HomepageAvatar.app
   ```
3. 마이크 권한을 물으면 **허용**을 누릅니다(말로 질문할 때만 씁니다).

### (선택) AI 답변과 음성 질문 켜기
키가 없어도 발표는 처음부터 끝까지 **ElevenLabs 목소리(아바타 Brian · 인터뷰어 Jessica)**로 나옵니다. 대본 음성을 앱에 함께 넣어 두었기 때문입니다.
키가 없을 때 직접 질문은 미리 만든 질문 목록(40개)에서 답하고, 그 답은 컴퓨터 내장 음성으로 말합니다.
`.env` 파일을 실행 파일과 같은 폴더에 두면 더 자연스러워집니다(형식은 `.env.example`).
- `ANTHROPIC_API_KEY` — 어떤 질문이든 홈페이지 내용을 근거로 답합니다. 홈페이지에 없는 내용은 지어내지 않고 "없다"고 답합니다.
- `ELEVENLABS_API_KEY` — 직접 질문에 대한 답도 아바타 목소리로 말하고, 🎤로 말한 질문을 알아듣습니다.
  한 번 만든 음성은 저장해 두어 같은 대사는 크레딧을 다시 쓰지 않습니다.

> 음성: ElevenLabs(elevenlabs.io) 무료 요금제로 만든 목소리입니다(비상업 · 수업 과제용).

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 화면 전체 | 실제 홈페이지 |
| 홈페이지 위 | 3D 아바타. 걸어 다니며 메뉴와 글을 손으로 가리킵니다 |
| 아래 가운데 | 자막. 말하는 글자를 따라 진하게 바뀝니다. 파란 이름은 인터뷰어, 주황 이름은 아바타 |
| 왼쪽 아래 | 일시정지 · 건너뛰기 · 질문 입력 · 🎤(말로 질문) · 현재 모드 표시 |

## 3. 발표 순서

1. **인사** — 아바타가 오른쪽에서 걸어 들어와 손을 흔들고 자기소개를 합니다.
2. **Works** — 메뉴 아래로 걸어가 위를 가리키면 손 모양 커서가 메뉴를 누릅니다. 작품 카드 옆으로 걸어가 팔을 뻗어 짚으며 소개하고, WFP 디지털게임 플레이 영상은 직접 열어 끝까지 틀어 줍니다.
3. **Papers** — CHI PLAY '26 Work-in-Progress 논문 옆에서 가리킨 뒤 글을 열어 본문을 천천히 내려 보여 줍니다.
4. **Assignments** — 과제 글을 하나씩 눌러 열고, 설명하는 동안 내용을 스크롤해 보여 줍니다.
5. **About** — 대표 문장, 관심 분야, 명함 QR을 차례로 짚으며 소개합니다.
6. **마무리** — 오늘 내용을 정리하고 제자리로 돌아와 90도로 인사합니다. **↻ 다시 보기** 버튼이 나타납니다.

## 4. 주요 기능

- **일시정지 / 이어 보기** — 버튼이나 스페이스 바.
- **건너뛰기** — 지금 장면을 끝내고 다음 페이지로 넘어갑니다.
- **직접 질문(글자)** — 입력란에 쓰고 **묻기**. 아바타는 지금 문장까지 말한 뒤 답하고, 하던 발표를 이어 갑니다.
- **직접 질문(말)** — 🎤를 누르고 말한 다음 🎤를 한 번 더 누릅니다(ElevenLabs 키가 있을 때).
- **모드 표시** — 왼쪽 아래 작은 글씨로 지금 쓰는 대본·답변·목소리·자료의 종류를 보여 줍니다.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 소리가 안 남 | 컴퓨터 음량과 출력 장치를 확인합니다. 키가 없으면 내장 음성으로 말합니다 |
| 두 사람 목소리가 비슷함 | 키가 없을 때 Windows 한국어 내장 음성은 하나뿐이라 높낮이로만 구분합니다 |
| 아바타가 메뉴를 못 누름 | 인터넷 연결을 확인합니다. 홈페이지가 열려 있어야 합니다 |
| 영상이 안 나옴 | 인터넷 연결을 확인합니다. 영상은 홈페이지에서 직접 재생합니다 |
